Control Naruto & Sasuke powers using your hands in real-time!
🚀 Overview
This project uses hand tracking to trigger visual effects inspired by Naruto and Sasuke. Simply show your hands to your webcam and watch the magic happen.
🧑‍💻 How to Use
1. Open `index.html` in your browser
2. Allow camera access when prompted
3. Show your hands in front of the camera
🎮 Controls
ActionEffect✋ Right Hand Open🔥 Naruto Power Activated✋ Left Hand Open⚡ Sasuke Power Activated🔵 Blue LinesHand tracking indicator
📋 Requirements
* 📷 Webcam
* 🌐 Modern browser (Chrome, Firefox, Edge, Safari)
* 📡 Internet connection (for MediaPipe library)
📁 Project Structure

```
project/
├── index.html          # Main application file
├── assets/
│   ├── naruto.mp4      # Naruto animation
│   └── sasuke.mp4      # Sasuke animation
└── README.md           # Documentation
```

⚠️ Note
The glow effect has been removed to ensure compatibility across all devices.
🛠️ Troubleshooting
*  ❌ Camera not working?  → Check browser permissions 
*  ❌ No blue lines visible?  → Ensure your room has proper lighting 
*  ❌ Videos not playing?  → Confirm that the `assets/` folder contains the required MP4 files
